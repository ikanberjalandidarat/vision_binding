What exactly do we keep in memory?

For each earlier frame, we keep two things:

1. A key calculated from that frame’s g.

2. The 64 visual numbers extracted from that image.

Earlier frame 0: key 0 + visual list 0
Earlier frame 1: key 1 + visual list 1
Earlier frame 2: key 2 + visual list 2

We store numerical lists, not object names or text descriptions.

Completed pilot 7246240. Scripted movement with privileged odometry.

“Retrieval” means mixing earlier lists

We compare the current g key with earlier keys.

Those comparisons give weights that add up to 1.

We multiply each earlier visual list by its weight, then add the lists.

Illustrative weights, not measured results:

recalled list = 0.1 × list 0 + 0.7 × list 1 + 0.2 × list 2

The recalled result is one list of 64 numbers. It can mix multiple earlier frames.

How do we make a prediction?

Join the 32 numbers in g with the 64 recalled numbers: 96 numbers total.

A learned layer converts these to 32 numbers called p.

Another learned layer converts p to 64 predicted visual numbers.

96 input numbers
32 intermediate numbers: p
64 predicted visual numbers

p is an intermediate calculation. Calling it p does not establish a biological place cell.

How does the model learn?

Compare the 64 predicted numbers with the current image’s actual 64 numbers.

Square each difference and average them. That is the prediction error.

Adjust the small model’s weights to reduce this error.

error = average of (prediction − actual value)²

The current visual list enters memory only after its prediction. Qwen does not change.

Why is this related to cognitive mapping?

The goal is to learn relationships between places and experiences.

We follow the idea of using movement to query memories of what was seen before.

Our current result shows useful retrieval. It does not yet show reliable place or grid cells.

The key question: does the model recognize the same place after a different journey?

Behrens et al. (2018), doi:10.1016/j.neuron.2018.10.002. Whittington et al. (2022), arXiv:2112.04035.

What comes next?

Visit the same locations by different routes.

Turn to different headings while staying at the same place.

Test whether location information survives those changes.
