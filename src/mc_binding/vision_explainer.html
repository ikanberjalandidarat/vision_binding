Layer selection: initial pilot versus expanded sweep

The initial pilot used 0, 7, 15, 23 and 31, chosen in advance as a coarse depth sweep: the first block, roughly quarter-depth, midpoint, three-quarter-depth, and final block of this 32-block vision encoder. Five sites make the first pilot manageable. We did not identify these as special “color layers” or select them because they worked. Layer numbers are zero-based: layer 0 is the first block’s output; layer 31 is the last output before the merger.

Orange = tested layers; outlined = currently selected trial. A single-layer trial edits one output. A group (shown with + signs) edits every listed output in the same forward pass, using that layer’s clean donor states. The expanded sweep tests all 32 individual layers and eight four-layer groups. Untested layers are not known to be ineffective.

What are patch-background-target0 and patch-background-target1?

target0 = evaluate the left object; target1 = evaluate the right object. For each, the runner randomly selects background positions equal in number to that target’s object tokens. It excludes both object bounding boxes (with a margin) and the crosshair-cover region. It copies donor background states at those same positions into the recipient.

The two filenames identify different control sets, not two background objects. Their token counts can differ because the two objects occupy different areas. The seed is fixed per target, so each target’s background set is reused across layers. Select background above, then switch target side to see exactly where each set lies.

Even with visually identical background pixels, later donor background states can contain information about the differently colored objects through attention. This control asks whether copying away from the object produces the target-color effect. Background controls match token count, not perturbation magnitude. For grouped random controls, magnitude is referenced to each clean recipient layer, not the already-modified live trajectory. Later overwrites may erase earlier effects; stronger group effects alone do not prove cooperation. Other-object controls use the neighbor’s natural token count. Random controls match target-patch delta magnitude in float32 before BF16 rounding.

Both flags must be true for the “specific transfer” count. False does not automatically mean a broken control: a self-patch is expected to preserve the original answers, and an other-object patch can change the neighbor instead. Neither flag measures shape preservation, object identity, or a reconstructed image.
