Train binding-conditioned navigation with recurrent PPO

Live RGB → frozen Qwen2-VL-7B vision encoder → visual features and predicted target map → learned GRU actor–critic → movement or stop → new RGB. No teacher actions or hand-written steering/stopping rules are used.

Implemented update

  • Collect four complete episodes under fixed policy weights (two in the execution smoke). Save visual inputs, predicted maps, actions, old log probabilities and values.
  • Compute GAE with discount 0.99 and lambda 0.95. Normalize advantages over the collected batch.
  • Perform up to four PPO epochs, shuffling episodes into minibatches of two. Replay each entire sequence from zero hidden state, preserving previous actions and temporal order. Stored collection hidden states are not reused under changed weights.
  • Clipped policy ratio 0.2, value MSE coefficient 0.5, entropy coefficient 0.01, gradient norm limit 0.5, Adam learning rate 3e-4.
  • Before the first update, replayed log probabilities must match collection within 1e-4. Approximate KL above 0.02 skips the pending minibatch update and stops further epochs. This is a safeguard, not a strict bound on realized policy change.

The batch boundary never cuts an episode. The task's fixed decision deadline is deliberately a true failure termination, just like the existing evaluator: terminal reward and zero bootstrap. This differs from an external collection truncation, which would require a next-state value. The GAE helper supports that distinction, but this runner collects complete finite-horizon episodes. The model is recurrent and can use history; it does not receive privileged distance or an oracle stop signal.

Matched binding controls

ArmInput to identical trainable map branch
zeroAll zeros
bindingPredicted 8×16 goal map, maximum score, no-proposal flag
shuffledMap spatial positions independently permuted each observation; scores and descriptors preserved

All arms run the same frozen encoder/readout and use image-derived chromatic proposals, not simulator boxes. The map has no ground-truth target location. The no-proposal flag means uncertainty, not world absence. The selector is a previously supervised readout trained with simulator labels; this is not end-to-end self-supervised RL. No new manual labels are needed.

Shared seeds and task schedules, identical episode caps and action duration. Actual transitions vary with stopping and are reported. This is not yet an equal-transition-budget benchmark. Training uses the existing near-to-far privileged spawn curriculum; initial/final evaluation uses original starts. Readout geometry splits are reused, with test geometries untouched. Validate reward, perception and rollout behavior as well as optimizer execution.

Start on Oscar

cd ~/projects/zef-binding
git pull
mkdir -p logs
sbatch scripts/slurm/binding_ppo.sbatch smoke

This submits three array tasks, one at a time. Each arm trains two episodes and evaluates two tasks under both greedy and sampled actions before and after training. It is only an execution smoke.

After smoke outputs are verified, run three seeds × three arms:

sbatch --array=0-8%2 scripts/slurm/binding_ppo.sbatch full

Full arm: 96 training episodes, 24 collection batches, and 64 evaluation tasks in each action mode before and after training. Maximum 96 decisions per episode; two simulator ticks per movement action. Check whether that task horizon permits arrival before interpreting failure.

Outputs and interpretation

runs/binding-ppo-ARRAYJOBID/seed-SEED-MODE contains manifest.json, initial.json, training.json, updates.json, final.json, summary.json, initial.pt and agent.pt. Update logs include KL, clip fraction, entropy, value loss, gradient norm and cumulative transitions. Per-decision files preserve action probabilities and binding inputs. report.html links actual movement GIFs and trajectories, with each GIF path printed.

Compare initial and final success separately for present and absent targets and for greedy versus sampled behavior. Compare the binding arm against both controls across seeds. A completed job or lower PPO loss is not evidence of navigation improvement. This stage has no donor patches; causal V30/V31 tests follow on a validated live learned policy.
