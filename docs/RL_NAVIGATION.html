Online RL, without manual region labels

There is no annotation review prerequisite. Existing scene metadata rebuilds the arena and supplies automatic reward/evaluation. The agent observes raw RGB features, a controlled-language instruction, its previous action, and recurrent memory. Boxes, positions, goal IDs, reward values, and teacher actions are not policy inputs.

A GPU smoke job runs two short training episodes and two validation episodes. If it exits successfully, an array runs nine experiments with at most two simultaneous GPUs. Each arm trains for 96 episodes and evaluates 64 fixed validation tasks, with at most 96 decisions per episode. Twelve-hour job limits bound resources. Each run records episodes, actions, rewards, GIFs, trajectories, checkpoints, and validation outcomes. Smoke success verifies execution, not learning. Use --dry-run to inspect commands. Fresh output tags only; no automatic retries or checkpoint resume yet.

Each arm uses seeds 731, 732, 733; the geometry split stays fixed at 731. Test geometry is not evaluated. Policies start from scratch. The frozen Qwen visual encoder supplies 8×16 features. A small recurrent policy/value network is trained by episodic on-policy actor-critic with entropy regularization. This is not PPO. Auxiliary prediction uses the next observed mean visual feature, with no attribute labels; it is an experimental objective and may not preserve object identity.

Terminal success is stopping within 0.8 blocks of the correct approach waypoint, or immediately stopping for a physically absent goal. Failure earns −1, success +1, nonterminal steps −0.01. Shaping adds γΦ(next)−Φ(current), with Φ=−min(distance,40)/20 and terminal Φ=0. Discount γ=.99. Distances are privileged simulator reward signals. Existing reviewed captures serve reset-integrity checks only; no new human annotations are requested.

Compare validation success, presence-conditioned success, and trajectories—not reward across different reward functions. These are repeated tasks in one controlled arena. Sparse exploration from scratch may fail within 96 episodes. Do not call this general autonomy or a binding mechanism. Reward and gradient unit tests are local; actual MineStudio/GPU execution is gated by the smoke job.
