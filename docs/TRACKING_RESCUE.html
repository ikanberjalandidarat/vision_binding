Does visual memory bridge recognition dropouts?

The previous template baseline could not select below the semantic threshold. Its 75/76 conditional accuracy matched frame-only selection, and its present-target panel omitted blue arches. This experiment fixes coverage and tests a different memory rule. It does not assume memory will improve results.

Balanced paired panel

Four validation families × four present goals (red/blue × pillar/arch), plus one absent episode per goal: 20 recorded teacher episodes. Sample every eight decisions plus start/middle/end. Reuse the frozen 8×16 readout and its threshold. No new training, manual annotations, or Minecraft collection.

Compare the same frames clean and with a fixed horizontal band (y=80…180) blended toward gray at 35% or 70%. Two corrupted sampled observations follow two initial clean observations; the six-observation cycle includes clean recovery. These are controlled appearance disruptions, not natural occlusion. Candidate boxes are identical across conditions and come from privileged geometry.

MethodSelection rule
Frame-onlyColor × shape score above the original threshold.
Original gated templateRerank above-threshold candidates with template similarity.
Recovery memoryAcquire a template from the model's own first accepted selection. Match all candidates, including below-threshold ones, with cosine ≥0.90 and a ≥0.05 margin. Abstain on ambiguity; reset after two misses. Never update from ground truth.

The memory settings are fixed development hypotheses, not validated optimal thresholds. A wrong acquisition may persist. Measure corrected and harmed frames, wrong selections, and longest consecutive wrong-selection streak per episode. Repeated frames are correlated; compare paired episode outcomes and family coverage, not an inflated independent-frame sample size.

V30 / V31 clean-to-corrupted interventions

At each corrupted observation, use the same-frame clean image as a privileged donor. Patch V activations at zero-based vision block 30, 31, or both, at token centers inside the corrupted band. Evaluate the stateless readout so memory does not confound the causal intervention.

  • Corrupted self-patch: must preserve scores and choice, otherwise stop the job.
  • Clean donor in the band: tests whether replacing these activations restores clean selection.
  • Equal-count clean donor outside the band: spatial control; this region is not necessarily background.

Count rescue only when the clean choice was correct and corrupted choice failed. Also count damage to correct corrupted choices. A donor-assisted rescue is not deployable performance and does not prove a binding-specific mechanism: color and shape information could both change. Memory receives no donor activations.

Scope and next gate

GIFs show recorded teacher movement with recovery-memory selections for all three image streams. The selector does not control movement. Geometry-filtered targets are excluded, not relabeled absent. Four absent episodes contain only initial frames, so they do not test memory after disappearance. A subsequent disappearance test needs longer absent or changing-scene sequences.

Advance only if memory improves paired disrupted selection without unacceptable wrong-object persistence, or a spatially specific donor intervention reveals a reproducible rescue. Then test held-out disruptions and automatic localization before reconnecting movement. Do not launch another navigation sweep from completion alone.

Recognition-first fallback update

The runner now also evaluates fallback_memory. Accepted per-frame recognition always wins and refreshes the template. Memory is consulted only below the existing 0.05 semantic threshold. Similarity and ambiguity gates remain unchanged, and memory-only matches never update the template. Scores are not calibrated confidence. Best cosine and margin are saved when memory is consulted. This is a development revision after validation inspection, not an independent confirmatory result.
