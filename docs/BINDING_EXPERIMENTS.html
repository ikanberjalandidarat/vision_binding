Binding and vision-head experiments: executable stage 1

Research plan · Prior evidence

Implemented: real four-object capture generation; isolated-object annotations for repeated colors; complete and absent-conjunction scenes; clean binding/color/shape baselines; gated Q/K/V head patches with strength, reverse direction and ablation controls; checkpointed results and screenshot/token-overlay HTML reports. No new Minecraft rendering or Qwen GPU success is implied by local unit tests.

1. Submit one real capture family

After you commit/push your changes and pull them on Oscar, submit from the repository root. Existing environments are reused.

git pull --ff-only origin main
mkdir -p logs

The output is /oscar/scratch/$USER/zef-binding/runs/binding-captures-1-JOBID. Monitor:

tail -F /oscar/home/zfawnia/projects/zef-binding/logs/binding-capture-JOBID.out

One family has 12 captures: four isolates, a full scene and an absent-object scene, for each of recipient and color-swapped donor. The manifest must finish with captured_needs_visual_review. Review the full/absent frames and boxes: all structures must be visible and separate, and no box may include its same-colored neighbor or the crosshair cover.

2. Run clean baselines before patches

sbatch scripts/slurm/binding_model.sbatch baseline \
  binding-captures-1-JOBID --reviewed-captures

Read binding-baseline-MODELJOBID/report.html, summary.json and gates/f0000.json. There are 44 clean questions per family: conjunction selection plus color/shape controls in full and absent scenes. Answers are ordinal digits, not world-coordinate IDs: count visible structures from left to right, starting at 1; 0 means the conjunction is absent. Every clean failure is retained, with the raw answer. Malformed answers are failures.

If the baseline fails, inspect ordinal parsing, shape recognition and absent-target responses separately. Do not treat a skipped patch run as a null effect. Prompts are fixed in source; any revised prompt constitutes a new development experiment.

3. Strength and head experiments

If the clean baseline fails, run calibration first:

sbatch scripts/slurm/binding_model.sbatch diagnostic \
  binding-captures-1-6949019 --reviewed-captures

This reuses the reviewed captures and writes a separate binding-diagnostic-JOBID directory. Each family receives 172 diagnostic questions: isolated shape/color checks, identical original prompts at 8 versus 64 generated tokens, concise prompts at 64 tokens, and yes/no conjunction-existence checks. Summary counts separate genuinely absent targets from present targets in three-object scenes. Reports preserve raw answers; original baseline scores and patch gates remain unchanged. This is development calibration, not held-out validation or permission to start patching.

sbatch scripts/slurm/binding_model.sbatch strength \
  binding-captures-1-JOBID --reviewed-captures

sbatch scripts/slurm/binding_model.sbatch heads \
  binding-captures-1-JOBID --reviewed-captures
PresetScope
baselineAll families in the dataset. No patches.
strengthFirst family only. V30, V31, V30+31; all heads; α = 0, .25, .5, .75, 1. Both intervention directions.
headsFirst family only. V30 and V31 independently; all heads plus each of 16 single heads; α = 1. Both directions.

Both patch presets include exact self controls, donor replacement, selected-channel norm-matched random perturbations, equally many background tokens, and image-token mean ablation. All four object regions are patched together for donor trials, preserving a well-defined counterfactual permutation of the four conjunctions. This is not a single-object specificity test. Mean ablation is a nonspecific disruption screen; apparent impairment alone does not establish a binding circuit.

Strength interpolates against the live recipient activations. In a group, the later block therefore interpolates its already-affected state with its independently captured donor value. α=0 and self replacement must reproduce the clean answer and digit scores. Errors stop the run and remove hooks.

Projection channels follow fused QKV order, then contiguous head channels. Q and K are supported by changing vision_patch_kind in a copied configuration; never overwrite a completed run's config. Each model run records source/config/environment/dataset hashes and refuses incompatible resume. The hook interface remains backward compatible with previous full-channel experiments.

Scores sum available single-token spellings for each first-answer digit, without renormalizing over the five choices. Report donor-minus-original log-probability and its change from the clean input. This is not the probability of a complete multi-token answer.

4. Expand only after the smoke checks

sbatch scripts/slurm/binding_capture.sbatch 24

This makes 288 images, with 24 permutations balancing each conjunction across four world slots. These are fixed-camera, same-arena development configurations, not independent worlds or held-out transfer scenes. After review, run the baseline on all 24. The intervention presets intentionally retain family_limit: 1; increase it explicitly in a separate config after inspecting the pilot and compute cost. To use that config, invoke python -m mc_binding binding-patch --dataset … --output … --config … --reviewed-captures inside an allocated GPU job.

Within a family, all 44 clean questions must pass before patching. Failed families are recorded and skipped; complete runs can have zero eligible families. Report both the full baseline denominator and the eligible-family patch denominator. Each complete intervention unit is an atomic checkpoint. Rerun the same CLI command with the same output directory to resume; a fresh sbatch submission otherwise gets a new job-ID output directory.

What this code does not yet implement

Decoder causal tracing, held-out geometry/viewpoint generators, another model backend, a continuously observing movement policy, learned memory, and training/RL remain later stages in the roadmap. Existing movement replay is still a privileged saved-choice controller. These new commands test binding and the V mechanism; they do not launch or claim autonomous-agent training.
