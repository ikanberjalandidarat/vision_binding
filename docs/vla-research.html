What we have done

  1. Frozen-model interventions: first patched final-token Q in the language decoder, then vision residual states and Q/K/V activations. V30 means the value projection at zero-based vision block 30. These were inference interventions, not policy training.
  2. Destination choice and scripted replay: tested selected destinations and executed movement with a controller. Scripted replay is different from a learned policy repeatedly interpreting new frames.
  3. Teacher demonstrations: collected 384 successful privileged-controller episodes. Teacher success is not learner success.
  4. Learned closed-loop policy: frozen visual features → 4×8 pooling → instruction-conditioned attention → recurrent memory → forward, left, right, stop. The small policy was trained; Qwen was frozen.
  5. Navigation ablations: varied visual preprocessing, loss weighting, and training seed. Reliable navigation was not achieved.
  6. Privileged perception: known object boxes plus small color/shape readouts. Finer grids succeeded on the current validation captures.

Current research pivot: hippocampal-inspired mapping

Train an odometry-assisted predictive memory during scripted Minecraft exploration, then inspect candidate g/p spatial activations on fixed allocentric maps. This is a new representation study, not evidence of learned navigation or biological place/grid cells.

Fixed approach benchmark: stopping remains unresolved

Four completed arms, including the separately preserved retry. With sampled actions, 4-tick near-target present successes increased from 2/12 to 5/12 (seed 731) and 2/12 to 4/12 (seed 732). Neither 2-tick arm improved its final count over initialization. All learning gates failed. Seed 732/chunk 4 reached the arrival radius on all 12 final greedy present probes, but never stopped and timed out. Original-start present navigation remained zero in every arm and mode. This isolates a stopping failure in that condition, not a binding mechanism.

What the maps and decision JSON mean

Action probabilities: [forward, turn_left, turn_right, stop]. The largest value determines the action. A 98.7% forward preference is not a 98.7% chance of reaching the target.

Policy attention: the instruction query weights 32 pooled visual regions, averaged across four controller heads. Indices run left-to-right through four rows of eight. This is not Qwen ViT-head attention and not a V30 patch mask.

Action Grad-CAM: positive gradient-weighted attribution at the pooled visual features for the selected action logit, with preceding memory fixed. If the action changes from forward to stop, the score being explained changes. Negative contributions are clipped; an all-zero map does not prove the image was ignored.

Heatmaps are smoothed and normalized independently per frame. Equal brightness is not equal attribution magnitude. Neither map is a segmentation or causal explanation. Interventions and behavior are needed to test causality.

Optional diagnostic: moving-frame perception

Freeze the successful 8×16 readout and threshold. Sample all 64 episodes at eight-decision intervals plus unique start/middle/end frames, generate geometry-based proposals, and explicitly audit visible regions, then evaluate attribute and visible-target selection accuracy by phase. No retraining and no new Minecraft collection.

Starting boxes cannot be reused after the camera turns. Object metadata gives identity, not visibility. This optional audit requires visible boxes or an explicit occluded/out-of-frame/uncertain label. Ambiguous frames are excluded from selection scoring. A target outside the view is not absent from the world.

  1. If audited live-frame recognition fails: investigate viewpoint/appearance shift.
  2. If it succeeds: replace privileged boxes with learned localization.
  3. Once selection generalizes: reconnect it to movement and collect corrective on-policy demonstrations.
  4. With a reliable clean baseline: revisit V30/V31 and head-level necessity/sufficiency interventions.
