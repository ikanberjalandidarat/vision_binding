Next experiment: select an object and maintain its identity

We pause broad navigation training. The question is whether frozen Qwen visual features and the existing color/shape readout can select the requested object in moving frames, and whether a simple visual template helps maintain that selection.

This is an offline diagnostic, not a new learned navigator. It reuses real teacher movement sequences from vla-demos-7045999. Their successful controller actions are not generated by either selector and must not be reported as selector navigation success.

Two directly comparable baselines

  • Frame only: apply the existing 8×16 readout to candidate regions and select the best goal score above its existing threshold.
  • Template memory: retain the visual feature vector of the first model-selected region. Rank subsequent candidates with log goal score plus 0.5 times cosine similarity to that template, retaining the same semantic eligibility threshold. No oracle correction, stable object index, coordinate or ground-truth attribute enters the selection function.

The memory weight is fixed in advance, not fit to these evaluation sequences. A wrong initial selection can persist; fewer identity switches alone is not success. This template is a simple baseline, not a trained recurrent tracker.

Automatic regions and honest limitations

Recorded object geometry and poses supply projected candidate boxes, using the existing camera calibration. Boxes are sorted by image position each frame. Known object identity and attributes are used for scoring only, except that geometry supplies privileged proposals and the requested goal specifies its color/shape. No human annotation or color-dependent acceptance filter is requested.

Projection ignores some occluders, view bob and HUD effects. Small, clipped and possible HUD/hand-overlap regions are automatically excluded. The resulting accuracy is conditional on accepted proposals, not autonomous detection accuracy. Out-of-view or rejected true targets are excluded from target accuracy, never relabeled world absence. World-absent episodes and exclusion counts are reported separately.

The existing readout was trained with simulator-derived attribute labels in the earlier privileged perception study. This run freezes it: no new labels or training are added. It diagnoses available visual information; it does not replace the eventual self-supervised/RL objective.

One GPU job prepares regions and evaluates both methods with shared extracted features. It reads 16 episodes spread across the readout's held-out validation families, including absent goals. Test geometries stay excluded. It samples every eight decisions plus start/middle/end frames. No Minecraft server, environment repair or new rendering is needed. The dependency is the existing model environment and the recorded demo/readout directories.

Output: /oscar/scratch/$USER/zef-binding/runs/target-tracking-JOBID/. The evaluation directory contains report.html, side-by-side overlay GIFs with paths beneath each GIF, results.json, episode-scores.json and summary.json. Yellow indicates the predicted region, gray indicates other privileged proposals. These are selection overlays, not attention, Grad-CAM or activation-patch masks.

How this leads back to binding interventions

If frame selection fails, investigate moving-view recognition before adding memory. If correct initial selection later changes to a distractor, inspect identity retention. If these work with privileged proposals, replace proposals with an image-driven detector/tracker before claiming autonomy.

Only after measuring these baselines should Q/K/V interventions test which encoder features change target selection or retention. A clean-to-corrupted rescue would then motivate training a memory or adapter, with unpatched donor-free evaluation. These intervention and training stages are not implemented in this diagnostic.

Local checks use synthetic non-Minecraft unit fixtures and a two-episode projection preparation smoke on recorded Minecraft data. Full Qwen inference remains an Oscar gate. Repeated frames are correlated and not independent trials.
