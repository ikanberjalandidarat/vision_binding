VLA pilot · Observed navigation failures

This pipeline tests two hypotheses without assuming either will fix navigation. It preserves the original policy, features, captures and demonstration frames. No activation patches or reinforcement learning are included.

What gets queued

Matched-input diagnostic (original policy) ──────────────────────┐
Original raw feature cache → raw / episode training → rollout ──┤
                           → raw / timestep training → rollout ─┤
Neutral-band feature extraction → neutral / episode → rollout ──┤
                               → neutral / timestep → rollout ─┤
                                                               ↓
                                                   Combined comparison report

Eleven jobs: one diagnostic, one new feature cache, four training runs, four Minecraft rollouts, and one comparison. Independent GPU feature/diagnostic jobs and CPU training jobs can run concurrently subject to Oscar scheduling. Minecraft rollouts are serialized to avoid multiple render processes competing for the shared simulator installation. No repeated manual sbatch commands are needed.

ArmPolicy inputTraining objective
raw-episodeOriginal full RGBEqual episode weight; baseline reproduction
raw-timestepOriginal full RGBEqual timestep weight in the expected sampled gradient
neutral-episodeGray top/bottom bandsEqual episode weight
neutral-timestepGray top/bottom bandsEqual timestep weight

The neutral input replaces rows 0–39 and 195–279 of raw 448×280 RGB with gray, preserving the central 155 rows and image dimensions. It removes tutorial/HUD/hand pixels, but also floor and ceiling information. It is a broad appearance ablation, not a clean identification of which nuisance caused failure. The same transformation is used at feature extraction and live rollout. Raw HUD recordings remain unchanged; attention/Grad-CAM are displayed on the actual transformed policy input.

Timestep weighting scales each episode's mean loss by episode length divided by mean training-episode length. With uniformly sampled episodes, its expected gradient equals the global per-timestep mean gradient. It retains the same number of optimizer updates, seed, architecture and epoch budget. Adam's adaptive updates mean this is not numerically equivalent to a single giant batch. It does not guarantee better stop/turn learning; minority-action metrics and real rollouts are essential.

Submit on Oscar

After you commit/push the changes and pull them on Oscar, run the following from the repository root. A preview does not submit jobs or create output directories.

cd ~/projects/zef-binding
export MC_BINDING_ENV="/oscar/scratch/$USER/zef-binding/envs/model"

"$MC_BINDING_ENV/bin/python" scripts/vla_ablation.py submit \
  --tag navigation-v1 --reviewed-captures --dry-run

"$MC_BINDING_ENV/bin/python" scripts/vla_ablation.py submit \
  --tag navigation-v1 --reviewed-captures

Defaults refer to the reviewed binding-captures-24-6961501, demos-7045999, features-7050533, policy-7052010 and rollout-7052970. Arguments --dataset, --demos, --cache, --policy and --rollout can override their directory names. The existing raw cache must match the original policy/demonstration provenance. All output goes to a new runs/vla-ablation-navigation-v1 directory on scratch. An existing tag is rejected.

The submission JSON records all job IDs and dependency commands. Dependent stages require successful parent completion. Invalid dependencies are configured to cancel rather than wait indefinitely. The final comparison runs after jobs terminate and explicitly reports missing/failed arms, rather than counting them as zero successes. A submission failure records jobs already submitted; inspect that file before retrying. There is no automatic resume of partial feature extraction or training.

Source code is hashed at submission and checked by each worker. Do not change the checkout while this suite is queued/running; otherwise pending workers deliberately fail to prevent mixing implementations. All stages use the existing environments; they never install packages. As before, a broken environment is an error, not a successful experiment.

What the diagnostic measures

  • For each original rollout starting frame, locate the matching teacher scene/goal and verify teacher frame provenance.
  • Encode teacher versus live starting images, both raw and with neutral bands. For each, evaluate all four color–shape instructions using fresh recurrent state and identical initial previous action.
  • Record expected teacher action, predicted action, four action probabilities, false stops on present targets and correct stops on absent targets.
  • Replay original held-out cached teacher sequences with teacher previous actions versus predicted previous actions. The images stay teacher-recorded: this is an offline history diagnostic, not navigation.

Masking a raw-trained model is itself a distribution change. A prediction change is diagnostic evidence, not proof of causality. Repeated frames/instruction swaps are paired measurements, not independent scenes. The report contains actual input images and every instruction's prediction.

Evaluation and decision rule

Each arm requests all 64 validation episodes across its four families within one validation geometry group. This replaces the original first-16 test-family rollout for development comparisons. Geometry groups stay together. Report present-target arrival and absent-target stop separately, immediate false stops, timeouts, startup accuracy and per-action recall. The combined report links each arm's raw Minecraft movement GIFs, trajectories, attention and action Grad-CAM. Neither map is a causal intervention.

Do not choose a revision using the test-family matched diagnostic or offline test scores. Use the validation comparisons to decide what to investigate, then freeze a chosen configuration before evaluating the full test split. A single seed and one arena are insufficient to establish general navigation competence. A “best” arm is not automatically selected, and the pipeline does not guarantee good navigation.
