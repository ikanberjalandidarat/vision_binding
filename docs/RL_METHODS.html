Which training method helps binding-conditioned navigation?

Four method arms share frozen Qwen features, the same actor architecture, reward function, action duration and task schedule. Each can receive zero, binding, or spatially shuffled target maps. All actions and stops come from the learned policy. No teacher replay or visual-servo controller is substituted.

Intrinsic reward contract

ICM/RND run only on training movement transitions, including the last movement at a task deadline. Stop receives no intrinsic bonus. Scores are computed before predictor updates; models remain fixed through collection of a batch. Scale raw errors by the prior training errors' RMS (initial scale 1), cap at 5, multiply by 0.001. Thus bonus is at most 0.005 per movement step versus the base step cost 0.01. This conservative coefficient is a hypothesis, not tuned optimal performance.

Predictors and their RMS statistics update only from training observations, after policy updates. Evaluation has zero bonus and no curiosity updates. Raw, scaled intrinsic and extrinsic rewards are stored separately. One episodic value head models the combined training reward; this is a simplified Qwen-feature curiosity adaptation, not the original RND dual-value implementation. Qwen and the existing supervised readout remain frozen.

Controls and scope

To match GRPO grouping, every method collects one shared task/start per batch. Actions differ between group members. Full groups contain four episodes. Epoch count, seeds and maximum episode length match; early stopping and actual transition counts differ and are reported. This is not equal wall time or equal transitions. Grouped scheduling is a change from the earlier PPO-only runner. Training curriculum uses privileged setup; actor inputs do not include coordinates or target labels.

All methods still need reliable arrival and stopping. Intrinsic reward is never counted as success. Compare before/after performance, task success across seeds, transitions, and zero/binding/shuffled map controls. All experiments are on development validation splits already used in earlier work; untouched test evaluation is a later gate.

One smoke array, then the factorial experiment

cd ~/projects/zef-binding
git pull
mkdir -p logs
sbatch scripts/slurm/rl_methods.sbatch smoke

Four jobs, two concurrent: PPO, GRPO, PPO+ICM, PPO+RND, seed 731, binding map. Each trains four episodes and evaluates two tasks before and after. This checks execution, not learning.

After the smoke passes, the complete comparison is 4 methods × 3 input modes × 3 seeds = 36 jobs (two concurrent):

sbatch --array=0-35%2 scripts/slurm/rl_methods.sbatch full

Outputs: runs/rl-methods-ARRAYJOBID/seed-SEED-METHOD-MODE. Summarize a smoke suite with:

python scripts/report_rl_methods.py /path/to/rl-methods-JOBID --expected 4

For the full suite use --expected 36. Missing or failed runs produce an incomplete comparison, never zero-success placeholders.

Other useful directions, not implemented here

  • Temporal identity consistency: train selection to remain consistent across nearby views and deliberate goal changes. This targets binding/memory directly; curiosity alone does not.
  • Successful-trajectory warm start: use existing teacher demonstrations or successful policy trajectories before PPO, then compare identical RL budgets. This adds supervised imitation, though no new manual labeling is needed.
  • Separate target choice from motor control: a learned goal selector and learned approach/stop controller may simplify credit assignment. Evaluate errors in both modules and their composition.
  • Goal relabeling: potentially learn from reaching the wrong object, but it requires valid relabeled rewards and an appropriate off-policy objective. Do not feed relabeled trajectories into PPO as though they were newly collected on-policy data.

Priority: PPO and PPO+RND as initial navigation baselines, GRPO if group returns vary, ICM if its inverse model learns meaningful action-dependent features. These are proposed priorities, not measured rankings. Keep method selection separate from claims of a causal visual-binding mechanism.
