A four-episode simulator smoke job gates an array of four runs, with at most two concurrent. The smoke exercises each near distance plus the original start. Success of the smoke means execution completed, not navigation succeeded. Use --dry-run to print commands without submitting. Outputs go to runs/rl-exploration-exploration-v1 on scratch. Fresh tags preserve prior results.

What to inspect

training.json records starts, rewards, success, action probabilities, entropy in nats, and gradient norms before clipping. validation.json separates greedy and sampled decisions. summary.json groups success by action-selection mode and target presence. Do not treat the pooled evaluation total as independent trials. Episode directories retain actual Minecraft movement GIFs, trajectories and simulator telemetry.

If only sampled actions succeed, inspect action preferences and deterministic loops. If near starts learn but original starts fail, exploration or transfer across starting positions remains unresolved. If neither learns even near the target, inspect gradients, stopping rewards and action execution before increasing the budget. None of these outcomes alone identifies a visual-binding mechanism. No activation patching is applied in this pilot.

Local tests use explicitly synthetic non-Minecraft fixtures. Real rendering and learning remain Oscar gates.
