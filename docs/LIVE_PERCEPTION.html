The run refuses unreviewed frames and verifies image hashes. It loads the existing 8×16 readout unchanged; no threshold adjustment. Visible-object color/shape recognition is reported even if another object is uncertain. Target-selection scores are omitted for frames containing uncertain or occluded identities, and for frames without any visible regions. Absence is visual absence among audited objects, not physical absence from the arena. No navigation success claim follows from these metrics.

Outputs: live-perception-JOBID/report.html, summary.json, results.json and provenance manifest. Keep results separate from capture validation metrics because viewpoint, appearance and sampling differ.
