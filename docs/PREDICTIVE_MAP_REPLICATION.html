Predictive coding cognitive-map replication

The reference is Gornet & Thomson, Automated construction of cognitive maps with visual predictive coding. Its official implementation is the reference subject. Keep its supplied notebooks and experiment workup intact. Do not run notebook installation cells. This project adds an external runner; it does not retrain or alter the author's model.

Order and claims

  1. Reference first. Check the official source revision and released data; run the predictive checkpoint on the saved environment, path, and circular-corridor arrays. Record next-image MSE, a position readout, and latent-versus-physical distances. The circular plot uses a 30-unit wrapped coordinate, as in the released analysis. Compare the plots and numbers to the paper before calling this a reproduction. The released saved arrays are not documented as independently routed held-out evaluation data. Their notebook also trains and evaluates the published position decoder on the same saved latents. Our ridge readout uses an 80/20 sequence-order split, but neighboring sequences may still leak route/scene information. Label both analyses descriptive.
  2. Frozen V-JEPA second. Use the same new Minecraft sequences for video and the repeated-last-frame control. Do not give either encoder coordinates, route IDs, or headings. Fit a position readout only on training trajectories; evaluate on independently routed held-out trajectories from the same world. Plot pairwise latent distance against world distance, conditioning on heading/view and temporal separation. Compare video and repeated-frame activations at the same layers. V-JEPA is a video representation model, not the reference's image-prediction decoder; next-image pixel MSE is not directly available from the frozen encoder.
  3. Eight worlds third. Apply the locked analysis and criteria to the diverse-v2 environments after steps 1–2. Existing 16 routes / 188 extracted clips are useful for a pipeline audit, but too sparse for strong place-field, gridness, or distance-geometry claims.

This tests spatial coding and spatial relationships. A latent-distance correlation alone is not a demonstrated cognitive map or grid/place cell. Route and view invariance, enough 2D coverage, and appropriate controls are required. Do not report gridness for a corridor.

Published comparison targets. Gornet and Thomson report a 5.04-lattice-unit mean position error with their trained position decoder, localized place-like latent fields, and unique combinations of active units for 87.6% of the sampled environment. Their reported r=0.827 concerns a specific latent-versus-physical distance relationship in the paper's path/circular-corridor analyses; it is not interchangeable with our random global-pair Spearman statistic. The paper does not establish a V-JEPA result or a grid-cell result. Our primary question is whether a frozen, general-purpose video model carries comparable route-stable spatial structure without Minecraft-specific backbone training; supervised readouts and later interventions must be named separately from zero-shot feature extraction. See the paper and official code.

Multiplying those values by 255 recovers visible Minecraft scenes. The original image comparison was blue because it displayed normalized channels with one shared percentile scale. Original-PNG and pixel-scale checks. The authors' repository tracks 82,630 validation PNGs. One original ten-frame episode was checked directly from Git: its RGB values span 0 to 0.996 after ordinary division by 255. It did not match any of the first 16 sequences in the released environment array after our proposed scale restoration (RGB MSE 0.093 to 0.227); the released array may contain a different subset or order. Temporal-leakage gate before spatial interpretation. In the official model source, the attention mask is triangular, but F.layer_norm(f, f.shape[1:]) normalizes over the temporal dimension as well as channels and spatial positions. Consequently, a statistic used for the output at frame 4 may include frame 5, which is that prediction's target. This is a source-level risk, not yet a measured effect. The external audit keeps the ten-frame input length fixed, substitutes only frame 5 or frame 9 from another original validation episode, and measures whether the frame-4 prediction or latent changes. If it does, prior MSE and per-frame latent maps must be described as full-clip analyses, not online predictions or causal per-frame states. Run this short check before the GPU distance experiment:

Across 135 sampled episodes (1,350 state rows), the first two columns span approximately 40.27×61.16 coordinate units; 50/64 bins are occupied on an 8×8 grid and 133/256 on a 16×16 grid. Next original-PNG distance experiment. The external path builder checks 24 candidate stretches distributed across the validation recording, each ten adjacent ten-frame episodes. It records source-state hashes and rejects a stretch if any within-episode or episode-boundary step moves more than 1.5 coordinate units, or if its spatial extent is under three units. The frozen reference-checkpoint runner accepts only a completed manifest with at least four continuous stretches. It applies the authors' image normalization and slides a ten-frame window along each verified 100-frame stretch. For each endpoint it keeps only the final native 128×8×8 activation, so no frame after that endpoint enters the forward pass even if full-clip normalization leaks future information to earlier activations. It compares physical distance with latent distance for pairs 5–90 frames apart within the same verified stretch, evaluates raw RGB distances on the identical pairs, and reports correlations separately by temporal-separation band. This is a descriptive control, not the paper's fitted log-distance model or an independent-route test; no position decoder or place-cell conclusion follows from it. Dense single-world Minecraft gate

Before V-JEPA map claims, collect a separately versioned world with an open, two-dimensional traversable area and two distant sites deliberately made visually similar. Keep the diverse-v2 source untouched. Record continuous RGB, actual XYZ and yaw, actions, collision/stuck checks, camera and tick timing, route IDs, world build/seed, and raw PNG hashes. Use several independent routes per site with opposite headings and at least one visually ambiguous pair. Require occupancy across the open area, same-location revisits from different headings, and near/far pairs at matched headings; show these counts before fitting a probe. Train/readout on whole trajectories and hold out whole trajectories, never random clips. No new architecture or learned memory is added to frozen V-JEPA.
